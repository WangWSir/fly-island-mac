## Fly Island for Mac v1.0.4

优化：**系统通知中心「清除」后，FlyIsland 秒级同步清空**（v1.0.3 需要等约 7–11 秒）。

### 问题

通知中心「清除所有」后，macOS 要过 **7–11 秒**才把删除写进 `usernoted` 数据库（实测采样：14:20:45 点击清除 → 14:20:52 数据库落盘）。FlyIsland 以数据库为事实来源，只能跟着慢。

### 修复

新增 UI 直读通道：监控通知中心面板（辅助功能），面板内横幅组从「有」变「无」即判定用户点了清除，**立即清空本地列表**，不等数据库。

- 实测：点击「清除所有通知」后 **0.4s** 内本地清空（数据库 7s 后才落盘）
- 带防抖：横幅归零需连续 2 次扫描（0.7s）才判定，避免渲染闪烁误清
- 面板关闭会重置状态，防止下次打开时误判
- 数据库对账继续兜底：单条划掉等场景仍走原路径（跟随系统落盘延迟）

### 安装

1. 下载 `FlyIsland-1.0.4-macos-universal.zip`（Apple Silicon + Intel 通用），解压后把 `FlyIsland.app` 拖进「应用程序」
2. 首次打开被 Gatekeeper 拦：右键 → 打开 → 再点「打开」，或 `xattr -dr com.apple.quarantine /Applications/FlyIsland.app`
3. 授权：系统设置 → 隐私与安全性 → **完全磁盘访问权限** 与 **辅助功能** → 勾选 FlyIsland
4. 重启应用

> 从 v1.0.0+ 升级：覆盖安装即可，无需重新授权。
