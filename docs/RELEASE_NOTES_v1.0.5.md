# v1.0.5

## 修复

### 设置页底部被遮挡

底部操作行（清空通知 / 清空剪贴板 / 版本 / 退出）原来放在滚动区内部，被 30pt 底部渐隐遮罩压暗，又紧贴岛的圆角下沿，视觉上像被裁掉一截。

改为**固定页脚**：

| 项 | 修改 |
|---|---|
| 位置 | 移出 ScrollView，固定在面板底部，滚不滚都在 |
| 分隔 | 上方加 0.5pt 分隔线，与滚动内容区分 |
| 间距 | 底栏中心距面板底 27pt，避开 30pt 圆角弧线 |
| 渐隐 | 只作用于滚动区（26pt），滚到底时最后一行能完整露出 |

四个标签页高度仍统一 296pt，不跳动。

## 完整功能

- **通知**：辅助功能读横幅做实时预览（~0.3s），usernoted 数据库做事实源；系统通知中心清空后 0.4s 同步清空本地列表
- **剪贴板**：文本/图片/文件历史，搜索、收藏、持久化，过滤密码管理器敏感类型
- **媒体**：读取 NowPlaying，封面/标题/歌手/单行歌词/进度，上一首 / 播放暂停 / 下一首
- **歌词**：按曲目请求网易云 / LRCLIB，LRC 按进度取当前行，本地缓存

## 安装

下载 `FlyIsland-1.0.5-macos-universal.zip`（Apple Silicon + Intel 通用），解压后拖进「应用程序」。

首次启动需在系统设置授权：

1. 隐私与安全性 → **完全磁盘访问权限** → 勾选 FlyIsland（读系统通知）
2. 隐私与安全性 → **辅助功能** → 勾选 FlyIsland（实时预览、全局 Esc）

未签名版本首次打开如被 Gatekeeper 拦截：

```bash
xattr -dr com.apple.quarantine /Applications/FlyIsland.app
```

## 系统要求

macOS 14.0+，带刘海的 Mac（MacBook Pro 14/16、MacBook Air 13/15 M2 及之后）
