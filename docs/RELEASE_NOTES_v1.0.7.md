# v1.0.7

## 修复

### 接扩展屏后岛仍显示在扩展屏

v1.0.6 只在启动时选一次刘海屏，有三种情况还会跑到扩展屏：

| 情况 | v1.0.6 表现 | v1.0.7 |
|---|---|---|
| 升级后没退出旧进程 | 旧代码继续跑，焦点在外接屏就跳过去 | 启动即按刘海屏定位（请先完全退出再打开） |
| 合盖外接（无内建屏） | 回退到扩展屏 | 默认**隐藏**，不在扩展屏出现 |
| 系统改分辨率/切 Space/被系统搬窗口 | 可能停在扩展屏 | 0.1s 自愈校验，窗口被搬走即拉回刘海屏 |

新增开关：**设置 → 常规 → 扩展屏显示**（默认关闭）。开启后，合盖或没有刘海屏时改在扩展屏顶部显示；关闭时保持隐藏，通知、剪贴板、媒体仍在后台运行。

隐藏状态下仍可从菜单栏图标唤起：**展开灵动岛**会临时贴在当前主屏，不会丢失入口。

## 完整功能

- **通知**：辅助功能读横幅做实时预览（~0.3s），usernoted 数据库做事实源；系统通知中心清空后 0.4s 同步清空本地列表
- **剪贴板**：文本/图片/文件历史，搜索、收藏、持久化，过滤密码管理器敏感类型
- **媒体**：读取 NowPlaying，封面/标题/歌手/单行歌词/进度，上一首 / 播放暂停 / 下一首
- **歌词**：按曲目请求网易云 / LRCLIB，LRC 按进度取当前行，本地缓存

## 安装

下载 `FlyIsland-1.0.7-macos-universal.zip`（Apple Silicon + Intel 通用），解压后拖进「应用程序」。

**升级务必先退出旧版本**（菜单栏图标 → 退出 Fly Island），否则旧进程会继续跑旧代码。

首次启动需在系统设置授权：

1. 隐私与安全性 → **完全磁盘访问权限** → 勾选 FlyIsland（读系统通知）
2. 隐私与安全性 → **辅助功能** → 勾选 FlyIsland（实时预览、全局 Esc）

未签名版本首次打开如被 Gatekeeper 拦截：

```bash
xattr -dr com.apple.quarantine /Applications/FlyIsland.app
```

## 系统要求

macOS 14.0+，带刘海的 Mac（MacBook Pro 14/16、MacBook Air 13/15 M2 及之后）。无刘海机型（Mac mini / Studio / iMac）贴在主屏菜单栏正中显示。
